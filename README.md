#### 🔄 [End-to-End MLOps Text Classification Pipeline](https://github.com/regkhalil/MLOps-Project)
Design and deployment of a complete MLOps pipeline for classifying 20 Newsgroups data.
* **Pipeline:** Ingestion, preprocessing, and model training (SGD, Naive Bayes, Logistic Regression) orchestrated by Apache Airflow
* **Tracking & Storage:** Experiment tracking and model registry managed with MLflow; artifacts stored on MinIO
* **Serving:** Containerized infrastructure (Docker Compose, Kubernetes/Kind) exposing predictions via a FastAPI backend
